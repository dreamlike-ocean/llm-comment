除目录图标外，SVG 文件逐字节保留上游 `icons/` 对应文件。
`folder.svg` 和 `folder-open.svg` 由上游 [3f585f46ad50134658fee6c63cc8f41ef353d32b 的 folderGenerator.ts](https://github.com/material-extensions/vscode-material-icon-theme/blob/3f585f46ad50134658fee6c63cc8f41ef353d32b/src/core/generator/folderGenerator.ts) 中的 `folderIcon` / `folderIconOpen` 原路径生成，
采用 [defaultConfig.ts](https://github.com/material-extensions/vscode-material-icon-theme/blob/3f585f46ad50134658fee6c63cc8f41ef353d32b/src/core/generator/config/defaultConfig.ts) 的默认色 `#90a4ae` 和 `0 0 16 16` 画布。
目录 SVG 仅封装上游生成器中的路径，不添加本项目绘制的形状。
